# Анализ рынка видеоигр (2000–2013)

Проект по предобработке и первичному анализу данных рынка игровой индустрии. Выполнен в рамках обучения аналитике данных.

**Автор:** Деньгина Анна Дмитриевна
**Дата:** 26.08.2026

---

## Цель проекта

Обработка и первичный анализ данных рынка игровой индустрии с 2000 по 2013 год для дальнейшего исследования: изучение структуры данных, их предобработка и фильтрация для получения нужного среза, а также категоризация данных.

---

## Данные

Источник: `new_games.csv` — информация о продажах игр разных жанров и платформ, а также пользовательские и экспертные оценки:

- `Name` — название игры
- `Platform` — платформа
- `Year of Release` — год выпуска
- `Genre` — жанр
- `NA sales`, `EU sales`, `JP sales` — продажи по регионам (млн копий)
- Пользовательские и экспертные оценки

Исходный датасет содержит 16 956 строк и 11 столбцов, охватывает период с 1980 по 2016 год.
> **Важно:** датасет `new_games.csv` — учебный, предоставлялся на образовательной платформе и не включён в этот репозиторий по условиям использования. Ноутбук отражает ход анализа и результаты, но для самостоятельного запуска потребуется подставить свой файл с аналогичной структурой данных.

## Основные результаты

- Названия столбцов приведены к единому стилю (`snake_case`)
- Исправлены типы данных: `eu_sales`, `jp_sales`, `user_score` приведены к `float64`, `year_of_release` — к `int32`
- Обработаны пропуски: удалены строки с пропусками в ключевых столбцах (`name`, `genre`, `year_of_release`)
- Данные отфильтрованы по периоду 2000–2013 годов
- Проведена категоризация игр по уровню пользовательских и экспертных оценок
- Выделен топ-7 платформ по количеству выпущенных игр: **PS2, DS, WII, PSP, X360, PS3, GBA** (лидер — PS2 с 2154 играми)
